⬡AgentDeck Bridge — 浏览器工具文档

AgentDeck 里的 coding agent 通过这 7 个工具操作你的浏览器。本页 = 全部能力清单 + 参数 + 示例。

调用链(一句话版)

agent 说人话 → pi/Claude 选工具(MCP)→ mcp.mjs → server.mjs(:7788)→ 本扩展 → Chrome

你只需要在 AgentDeck 窗格里说「打开 xx 页面截图看看」;模型读过下面的工具描述,自己决定调哪个。

接入方式

agent 侧注册一次(全局生效):

pi mcp add agentdeck-browser -- node /path/to/agent-deck/mcp.mjs
claude mcp add agentdeck-browser -- node /path/to/agent-deck/mcp.mjs
codex mcp add agentdeck-browser -- node /path/to/agent-deck/mcp.mjs

调试/手工场景也可以直接 curl(与 MCP 等价,同一入口):

curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"navigate","args":{"url":"https://example.com"}}'

7 个工具

browser_navigate写
打开 URL 并等待页面加载完成(最长 8 秒)。返回 tabId / url / title。标签开在专属「AgentDeck」标签组里,复用组内已有工作标签。
参数类型说明
urlstring 必填要打开的绝对地址
tabIdnumber 可选显式指定目标标签页
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"navigate","args":{"url":"https://x.com"}}'
browser_screenshot读
对当前工作标签整页截 PNG。两张交付:图片内联返回(多模态模型直接"看见")+ 落盘 ~/.agent-deck/shots/(路径在结果里,可 open 查看)。
参数类型说明
tabIdnumber 可选显式指定目标标签页
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"screenshot"}'
# → {"ok":true,"path":"/Users/you/.agent-deck/shots/shot-....png",...}
browser_click写
按 CSS 选择器点击元素,点击前自动滚动到可视区。返回被点元素的标签与文本片段。
参数类型说明
selectorstring 必填CSS 选择器,如 #submit、a.search
tabIdnumber 可选显式指定目标标签页
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"click","args":{"selector":"#submit"}}'
browser_eval_js写
在页面主世界执行任意 JS,支持 await Promise,返回可 JSON 序列化的值。万能逃生舱:拿 DOM 数据、查接口状态都靠它。
参数类型说明
expressionstring 必填JS 表达式,如 document.title
tabIdnumber 可选显式指定目标标签页
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"eval_js","args":{"expression":"document.querySelectorAll(\"a\").length"}}'
browser_read_text读
读取页面可见文本(body.innerText),适合让 agent 快速理解页面内容。默认上限 4 万字符。
参数类型说明
limitnumber 可选字符上限(默认 40000,硬顶 200000)
tabIdnumber 可选显式指定目标标签页
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"read_text","args":{"limit":10000}}'
browser_tabs_list读
列出当前所有标签页(id / title / url / active / agentGroup)。agentGroup:true 表示该标签在专属 AgentDeck 组内。
参数类型说明
无参数
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"tabs_list"}'
browser_close_tab写
关闭标签页,默认关 agent 自己的工作标签。组空了会自动消失,下次操作自动重建。
参数类型说明
tabIdnumber 可选缺省 = 关 agent 工作标签
curl -s http://127.0.0.1:7788/api/browser/cmd -d '{"op":"close_tab"}'

标签页隔离规则(Codex 式)

  • agent 拥有专属窗口(首次操作自动创建,不抢焦点),窗口内再设专属标签组「AgentDeck」(紫色)。你自己的窗口永远不会有 agent 的标签,也永远不会看到调试横幅
  • 调试横幅是窗口级的——正因为任务被关在独立窗口,横幅只出现在 agent 自己的窗口里;且只有 browser_eval_js/browser_screenshot 瞬间触发,用完即断
  • 目标解析顺序:显式 tabId → 组内已有工作标签 → 在专属组里新建
  • 想让它操作某个已有页面:让它先 browser_tabs_list 找到 id 再指定;或把那个标签拖进 AgentDeck 窗口的组里
  • 窗口/组被关闭后,下次操作自动重建;标签组标题与颜色可随时在浏览器里自定义

安全边界

  • 配对:AgentDeck UI 点「连接浏览器」→ 浏览器弹窗确认,token 自动管理;nonce 一次性、2 分钟过期
  • 网页隔离:插件信道在握手层拒绝一切网页 Origin,恶意网页无法连接或抢答配对
  • 可见性：只有 browser_eval_js 和 browser_screenshot 两个操作会短暂触发 Chrome「已开始调试」横幅（用完立即断开，闪现即逝）；导航/点击/读文本全程无横幅
  • 尚缺(P2):域名防火墙、专用 Profile、敏感操作人工确认、审计日志——请只在信任的 agent 任务上使用
